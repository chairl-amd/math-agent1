# 给别人用：三分钟跑起来（大白话版）

这份文档只解决一件事：**换一台电脑，怎么把这个"数学公式校验"跑起来。**

不用懂代码，照着做就行。全程只有三步。

---

## 第 0 步：先看看文件夹里有没有 `.python312`

打开项目文件夹，看一眼有没有一个叫 `.python312` 的文件夹：

- **有** → 说明 Python 和依赖都打包好了，**直接跳到第 2 步**。
- **没有** → 需要自己装 Python，做第 1 步。

> 解释一句：`.python312` 就是一个"自带的小号 Python"，有它就不用另装。

---

## 第 1 步（只有没自带 Python 才做）：装 Python + 装依赖

1. 打开 <https://www.python.org/downloads/>，下载 **Python 3.12**（Windows 版）。
2. 双击安装包，**一定要勾选最下面那个 `Add python.exe to PATH`**，然后点
   `Install Now`。
3. 装完后，在这个项目文件夹里**空白处按住 Shift + 鼠标右键** → 选
   "在此处打开 PowerShell 窗口"（或"打开终端"）。
4. 在窗口里粘这一行，回车：

   ```text
   pip install -r requirements.txt
   ```

   等它自己转完（几分钟，取决于网速）。看到 `Successfully installed ...` 就成了。

> 如果公司网络卡，可以先把 `pip install` 换成国内的：
> `pip install -r requirements.txt -i https://pypi.tuna.tsinghua.edu.cn/simple`

---

## 第 2 步：填你自己的 Key（这步不能省）

1. 找到 `.env.example` 这个文件（注意文件名开头有个点，可能被系统藏起来）。
2. **复制**一份，把副本改名成 **`.env`**（前面那个点要保留，后面不要 `.txt`）。
   - 小技巧：在地址栏输入 `cmd` 回车，然后敲 `copy .env.example .env`。
3. 用记事本打开 `.env`，把这两行换成你自己的 Key：

   ```text
   DEEPSEEK_API_KEY=YOUR_DEEPSEEK_KEY_HERE
   DASHSCOPE_API_KEY=YOUR_DASHSCOPE_KEY_HERE
   ```

   **注意**：`=` 后面直接写 Key，不要加引号，不要留空格。
4. 保存、关掉记事本。

关于这两把 Key：

- `DEEPSEEK_API_KEY` 是**必须**的，没有它任何校验都跑不了。
- `DASHSCOPE_API_KEY`（Qwen）是**可选**的，不填也能跑，只是少一路"第二意见"，
  个别疑难图会更保守地显示"需人工复核"。
- 两个 Key 都要**你自己去对应平台申请并充值**。别用别人的 Key，也别把
  `.env` 发给任何人。
- 每次调用模型都会**花钱**，跑几十张图通常也就几毛到几块。

---

## 第 3 步：双击 `start.bat`

1. 双击项目文件夹里的 **`start.bat`**（黑色窗口会弹出来，这是正常的）。
2. 窗口里会打印一行：

   ```text
   [INFO] open    http://127.0.0.1:7860
   ```

3. 打开浏览器（Chrome / Edge 都行），地址栏输入：**<http://127.0.0.1:7860>**
4. 页面出来就成功了。用的时候**别关那个黑窗口**，关掉服务就停了。

> 想先不启动、只检查环境对不对：双击后在文件夹地址栏敲
> `cmd`，然后执行 `start.bat --check`，它会逐项告诉你 Python、依赖、Key 有没有就位。

---

## 第一次怎么确认"真的能用"

按顺序看三件事：

1. **页面能打开** → 说明服务和依赖没问题。
2. **页面右上/中间没有报错红字**，能看到上传图片的框 → 说明前端正常。
3. **传一张公式截图，点"开始校验"，等 10~40 秒**：
   - 出现"通过 / 不通过 / 需人工复核"的结论 → **完全成功**。
   - 出现"模型调用失败 / API Key 无效" → 是第 2 步的 Key 没填对，回去检查 `.env`
     （保存了吗？文件名真的是 `.env` 吗？Key 有没有多余空格？）。
   - 出现"图片读不出来" → 换一张清楚点的截图试试。

> 项目自带的 `tests/benchmark/` 里有 50 张现成的测试图（`correct/`、`incorrect/`
> 等子文件夹），随便挑一张拖进去就能试，不用自己找题。

## 常见问题

**Q：双击 `start.bat`，黑窗口一闪就没了。**
说明环境有问题。用这个办法看原因：在文件夹地址栏敲 `cmd` 回车，然后输入
`start.bat` 回车 —— 窗口就不会自动关，能把报错看全。

**Q：提示端口被占用（7860）。**
在 `.env` 里加一行 `MATH_AGENT_PORT=7861`，保存后重新双击 `start.bat`，
浏览器改开 <http://127.0.0.1:7861>。

**Q：提示找不到 Python。**
要么把 `.python312` 文件夹放回项目根目录，要么按第 1 步装 Python 3.12 并勾选
`Add python.exe to PATH`。

**Q：电脑上没有 D 盘，能用吗？**
能。这套东西**不依赖 D 盘**，放在哪个盘、哪个文件夹都能跑（路径都是相对的）。

**Q：要不要联网？**
要。识别和校验都要调用云端模型，断网就只能看界面，点校验会失败。

**Q：为什么有些题显示"需人工复核"？**
这是设计如此。手写特别潦草的撇号、连续偏微分方程 vs 离散实现这类题，
机器给不出可靠结论时会**如实说不知道**，而不是硬判一个对错。

**Q：我不想让它自动调用那么多的模型，能省点钱吗？**
在 `.env` 里加 `EXPLAIN_ENABLED=0`（关掉"批改说明"），或
`HETERO_VERIFY_ENABLED=0`（只用本地符号计算，不调第二意见模型）。

---

## 一句话总结

> 有 `.python312` 就填 `.env` → 双击 `start.bat` → 开
> <http://127.0.0.1:7860>；没有就先装 Python 3.12 再 `pip install -r requirements.txt`。

如果还是起不来，把 `start.bat --check` 打印的那几行发给我，一眼就能看出缺什么。
